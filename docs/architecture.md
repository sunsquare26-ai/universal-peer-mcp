# 구조

Claude MCP는 짧게 실행되는 MCP 입구와 계속 살아 있는 로컬 데몬을 나눕니다. MCP 입구가 닫혀도 데몬은 답변과 전달 상태를 받을 수 있습니다.

```text
로컬 MCP 클라이언트 → stdio MCP 입구 → 사용자 전용 데몬 → Claude 로컬 어댑터 → 실행 중인 Claude Code
                                      ↘ 사용자 전용 사건 기록
```

사용자는 대상마다 별칭을 정하지만, 별칭이나 화면의 이름은 권한 근거가 아닙니다. 전송 직전에 세션 식별자, 작업 폴더, 프로세스 번호와 시작 시각, 같은 사용자가 소유한 소켓, 권한 실행 인자를 함께 확인합니다. 화면 이름이 달라지면 기록만 남기며 정상 연결을 끊지 않습니다.

메시지는 호출자가 준 ID와 내용 해시를 먼저 디스크에 기록한 뒤 한 번만 보냅니다. 같은 ID와 같은 내용은 앞 결과를 돌려주고, 같은 ID에 다른 내용이 들어오면 거부합니다. 연결 실패나 프로세스 종료 뒤에는 자동으로 다시 보내지 않습니다.

사건 기록은 같은 사용자 계정 안에서 재시작을 견디기 위한 append-only 파일입니다. 위변조 방지 원장이 아닙니다. 마지막에 쓰다 끊긴 한 줄만 복구할 수 있고, 중간이 깨지면 닫힌 상태로 멈춥니다.

최신 MCP 요청은 연결 초기화 없이 요청마다 규격 버전과 클라이언트 기능을 보냅니다. 현재 일부 호스트가 쓰는 예전 초기화 방식은 별도 어댑터에 가두며, 두 방식의 상태를 섞지 않습니다.
